Un flujo sin saltos

Tres etapas. Un solo espacio.

La misma herramienta acompaña la construcción, el movimiento y la salida final del personaje.

01
▱

Importa y ensambla

Carga imágenes o un PSD por capas, organiza cada pieza y alinea el personaje sobre el lienzo.

Sprites modulares · capas reales
02
⌁

Articula el rig

Define una jerarquía de huesos, vincula las piezas y ajusta cadenas IK para posar con naturalidad.

Jerarquía · pivotes · cinemática inversa
03
▶

Anima y exporta

Crea clips, guarda fotogramas clave y exporta un paquete autocontenido listo para integrar.

Timeline · múltiples clips · runtime web
